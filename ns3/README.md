# ns-3 VANET backend

Replaces the analytic communication channel with a **real IEEE 802.11p
(WAVE) Basic-Safety-Message simulation**. PDR, latency and Age-of-Information
then *emerge* from the ns-3 PHY + MAC + the SUMO/IDM vehicle mobility instead of
being configured.

```
data/vanet/mobility_<...>.tcl   <-- equipped-vehicle trajectories (ns-2 format)
        │  (src/vanet/mobility_export.py)
        ▼
ns-3  scratch/vanet-beacon      <-- 802.11p, YansWifiChannel, LogDistance/Nakagami/Friis
        │                            every equipped vehicle broadcasts a BSM at 10 Hz
        ▼
data/vanet/reception_<...>.csv  <-- event,t,gen_t,node,peer,dist_m   (tx + rx rows)
        │  (src/vanet/ns3_channel.py)
        ▼
PartialObservation  (mask / AoI / observed_state)  -- same object the rest of the
                                                      pipeline already consumes
```

A BSM generated by vehicle *v* at time *g* is **collected** by the traffic
system if ≥1 *other* equipped vehicle receives it (V2V backhaul assumed).

## Build

```bash
bash ns3/setup_ns3.sh          # clone ns-3.42 into ./ns-3-dev and build vanet-beacon
                              # (~20-40 min, ~3 GB; needs g++, cmake, ninja)
export NS3_DIR=$PWD/ns-3-dev  # setup_ns3.sh also appends this to ~/.bashrc
```
Already have ns-3? `NS3_DIR=/path/to/ns-3 bash ns3/setup_ns3.sh` just copies the
scratch program and rebuilds it.

## Use

```yaml
# config.yaml
vanet:
  backend: ns3          # <- switch from 'analytic'
  ns3:
    propagation: LogDistance   # LogDistance | Nakagami | Friis
    tx_power_dbm: 20
    beacon_hz: 10
    phy_mode: OfdmRate6MbpsBW10MHz
```
```bash
python scripts/simulate_vanet.py --quick
```

If ns-3 is not found or the run fails, the pipeline logs a warning and falls
back to the analytic channel — nothing hard-fails. The `comm_backend` column in
`outputs/tables/vanet_results_raw.csv` records which backend produced each row,
plus `realized_pdr` / `realized_latency_ms` measured from the ns-3 trace.

## Manual run

```bash
cd $NS3_DIR
./ns3 run "vanet-beacon --mobility=$OLDPWD/data/vanet/mobility_x.tcl \
    --nNodes=120 --duration=1800 --beaconHz=10 --txPowerDbm=20 \
    --propagation=LogDistance --rxTrace=/tmp/rx.csv --seed=42"
```

## Notes

* Tested against ns-3.40 / 3.41 / 3.42 with modules
  `core network internet mobility wifi wave applications propagation stats`.
* The corridor is modelled as a 1-D line (X = metres along the corridor); only
  distance matters for the propagation models used, so orientation is irrelevant.
* Non-equipped vehicles are *not* ns-3 nodes (they carry no radio); penetration
  is realised by how many vehicles get an OBU.
